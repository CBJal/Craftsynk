06
Buttons

Four variants × three sizes. Always use .btn as the base class paired with a variant modifier.

Primary — .btn.btn-primary
Ghost — .btn.btn-ghost
Secondary — .btn.btn-secondary
Danger — .btn.btn-danger · destructive actions only
◎
Shine Animation
Primary and ghost buttons run a continuous shimmer sweep (btn-shine keyframe). This reinforces the premium, polished feel. Never suppress it for brand-facing buttons.
07
Glass Components

Glassmorphism is the defining aesthetic. All public-facing surfaces use it. Admin UI uses flat surfaces intentionally — utility over decoration.

glass card

The Primary Surface

Use .glass for hero elements and prominent content blocks. Hover adds lime border glow. backdrop-filter: blur(24px).

glass tab

The Supporting Surface

Use .glass-tab for bento cards, process steps, and grid items. Subtle variant — less blur, more structure.

Interactive badge
Accepting projects — Q3 2026
Use .avail-badge + .avail-dot. The dot pulses via the blink keyframe.
Section label
What we do
Use .label above all section headings. 11px · 700 · UPPERCASE · +12% tracking. Preceded by an auto-generated 18px lime dash.
Glassmorphism Principles
Blur
backdrop-filter: blur(24px)
Never less than 20px on glass surfaces
Background
rgba(255,255,255,0.048)
Very low opacity — the blur does the work
Border
1px solid var(--glass-border)
Always 1px, never thicker on glass
Hover State
border-color: var(--lime-border)
Lime border on hover — consistent across all glass

10
Motion & Interaction

A single custom easing curve drives all transitions. Motion is intentional — it reinforces the premium, structured brand voice.

Easing Curve — --ease
cubic-bezier(0.16, 1, 0.3, 1)
Fast start, elastic overshoot, smooth settle. Communicates energy without feeling erratic. Applied to all hover, reveal, and UI transitions.
0ms — start→ fast acceleration →settle
Duration Tokens
--t-fast 200ms
Hover states, color transitions
--t-med 350ms
Cards, modals, panels
--t-slow 600ms
Reveal animations, page transitions
Hover Interaction Patterns (move your cursor over each)
Card Lift
translateY(-4px) + border-color → lime-border + box-shadow
--t-med + --ease
Button Float
translateY(-2px) + lime glow box-shadow
--t-fast + --ease
Text Glow
color → lime-text + text-shadow lime glow on nav links & footer links
--t-fast
◎
Scroll Reveal — .reveal → .visible
Every section block uses .reveal. IntersectionObserver adds .visible on entry. translateY(28px) → 0 over 600ms. Stagger with transition-delay on sibling elements (0.06s increments).
